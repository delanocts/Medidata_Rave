● Two of these are read by the running tool, not only by a person: data-rules.md goes into every generation prompt, and error-codes.md decides what a Rave rejection means. Editing either changes behaviour with no code change.

Timings are from a real run: 4 subjects in 30.6 minutes, 15–17 minutes each, running concurrently. Roughly three quarters of that is Rave answering one POST at a time — Rave charges per message, not per value, so a form with ten fields costs about what a form with a hundred does. That is why the subject lanes, not the stages before them, are where the time goes. Run it yourself with python scripts/run_all.py --study aes-001.
